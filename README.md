# Gemini 3.8 Flash 실시간 화면 · 오디오 번역기

Google AI Studio(`google-genai` SDK)의 **`gemini-3.8-flash`**(기본값, 변경 가능) 모델을 사용하여 **PC 디스플레이/특정 애플리케이션 화면의 텍스트**와 **실행 중인 프로그램 또는 특정 크롬 탭의 오디오**를 실시간으로 한국어(또는 다른 언어)로 번역해 주는 Windows 데스크톱 애플리케이션입니다.

---

## 1. 새 PC에 설치 및 실행하는 방법

이 프로젝트 폴더 전체를 새 PC에 복사한 후 아래 순서대로 진행하면 바로 사용할 수 있습니다.

### 사전 준비
1. **Windows 10 / 11** 환경
2. **Python 3.10 이상** 설치: [python.org/downloads](https://www.python.org/downloads/)
   - ⚠️ 설치 첫 화면 하단의 **`Add Python to PATH`** 체크박스를 반드시 체크하세요.
3. **Google AI Studio API 키 발급 (무료 티어 사용 가능)**:
   - [Google AI Studio (aistudio.google.com/apikey)](https://aistudio.google.com/apikey)에 접속하여 **`Create API key`**로 키를 발급받습니다.
   - 별도 유료 결제 없이도 무료 티어(Free Tier)로 `gemini-3.8-flash`를 무료로 사용할 수 있습니다.

### 원클릭 패키지 설치 (`install.bat`)
1. 폴더 안의 **[`install.bat`](file:///c:/Users/carro/Documents/antigravity/amazing-pasteur/install.bat)** 파일을 더블클릭합니다.
2. 자동으로 가상환경(`.venv`)을 생성하고 [`requirements.txt`](file:///c:/Users/carro/Documents/antigravity/amazing-pasteur/requirements.txt)에 명시된 필수 패키지(`google-genai`, `pillow`, `pycaw`, `pyaudiowpatch` 등)를 설치한 뒤 자체 테스트(`self_test OK`)까지 완료합니다.

- 또는 터미널에서 직접 실행할 수도 있습니다:

## 2. 주요 기능 및 사용법

### ① Google AI Studio & 모델 설정
- **API Key**: 발급받은 API 키를 입력하고 **`[설정 저장]`**을 누르면 `translator_config.json`에 저장되어 다음 실행 시 자동으로 불러옵니다.
- **번역 모델**: 기본값은 **`gemini-3.8-flash`**이며, 드롭다운에서 `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`, `gemini-4-argon` 등으로 즉시 변경할 수 있습니다.

### ② 화면 / 애플리케이션 텍스트 실시간 번역
- **전체 디스플레이 영역**: 모니터 화면 어디든 **`[📐 영역 드래그 지정]`**으로 사각형을 그리면 해당 위치의 텍스트가 바뀔 때마다 실시간 번역합니다.
- **지정 애플리케이션 창**: 현재 실행 중인 프로그램 창을 드롭다운에서 선택하고 영역을 지정하면, 해당 창이 이동하더라도 창 기준 상대 좌표를 추적하여 번역합니다.
- **`[화면 번역: ON/OFF]`** 버튼으로 언제든 켜고 끌 수 있습니다.

### ③ 오디오 사용 프로그램 및 크롬 탭별 분리 번역
- **실행 중인 프로그램 오디오 모드**:
  - 현재 오디오 세션이 활성화된 프로그램 목록과 실시간 소리 출력 여부(`🔊 재생 중`)를 자동으로 탐지합니다.
  - 원하는 프로그램을 선택하고 **`[오디오 번역: ON]`**을 켜면 해당 프로그램에서 소리가 날 때 음성을 인식해 실시간 번역 자막을 출력합니다.
- **크롬 탭별 단독 오디오 분리 모드**:
  - **`[🌐 크롬 탭 오디오 선택 창 열기]`** 버튼을 누르면 크롬에 탭 캡처 브릿지 페이지(`http://127.0.0.1:8765`)가 열립니다.
  - **`[1. 번역할 크롬 탭 선택하기]`**를 누르고 원하는 크롬 탭 하나를 선택(하단 *"탭 오디오도 공유"* 체크)하면, 다른 크롬 탭이나 PC의 다른 소리와 전혀 섞이지 않고 **선택한 탭의 오디오만 분리**하여 번역합니다.

### ④ 분리형 번역 결과(자막) 창 커스터마이징
- 제어판 창과 **번역 결과(자막 오버레이) 창**이 별도의 창으로 분리되어 있습니다.
- **배경 투명도 슬라이더**: `15%` ~ `100%` 사이로 실시간 투명도 조절
- **위치 및 크기 변경**: 자막 창 상단 바를 드래그하여 원하는 위치로 이동하고, 우측 하단 모서리 그립을 끌어 크기를 자유롭게 변경
- **글자 크기 조절 / 항상 위 / 마우스 클릭 투과(Click-through)**: 영상이나 게임 위에 자막 창을 띄워 두고 마우스 클릭이 뒤쪽 창으로 그대로 통과하도록 설정 가능

### ⑤ 토큰 및 할당량 잔여량 대시보드
- 매 번역 요청마다 반환되는 실제 토큰 사용량(`Input`, `Output`, `Total`)을 집계합니다.
- **무료 티어(Free Tier)** 및 **유료 티어** 기준 **분당 잔여 요청 수(RPM)**, **분당 잔여 토큰 수(TPM)**, **일일 잔여 요청 수(RPD)**, 그리고 **일일 토큰 예산 대비 잔여 토큰 수(%)**를 프로그레스 바로 실시간 확인할 수 있습니다.
